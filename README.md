# ngram-based-noun-classification

This site provides data and scripts used for presentation at NLP31/2025 by Kow Kuroda.


# Scripts

[noun-classifier-batch-runner](noun-classifier-batch-runner.ipynb) is the Jupyter notebook that analyzes data and produces results.

[extract-accuracies-from-results](extract-accuracies-from-results.ipynb) is the Jupyther notebook that extracts accuracies and integrate them.


# Helpers

[Morfessor](https://github.com/aalto-speech/morfessor) is used to generate segments more complex than simple characters. Segments with different sizes can be generated by  [generate-Morfessor-models](Morfessor/generate-Morfessor-models.ipynb). Segments generated under morph_length = [1.5, 2.0, 2.5, 3.0, 3.5, 4.0] are incorporated in noun-classifier-batch-runner above.
